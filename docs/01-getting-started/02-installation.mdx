## Requirements

- **American Truck Simulator** or **Euro Truck Simulator 2**, 64-bit, on Windows.
- The **DirectX 11** renderer, which is the game's default. Sightline does not work with DirectX 12 or OpenGL.

> [!NOTE]
> Tested on ATS 1.62.1.1 with one monitor and with two monitors in AMD Eyefinity. Euro Truck Simulator 2 uses the same engine and is supported, but it has not been tested yet.

## Install

::::steps

### Close the game

The game only loads plugins when it starts.

### Copy the plugin

Copy `sightline.dll` to the `plugins` folder inside the game's installation folder. Create the `plugins` folder if it does not exist.

```
<game folder>\bin\win_x64\plugins\sightline.dll
```

For Steam, the game folder is usually `C:\Program Files (x86)\Steam\steamapps\common\American Truck Simulator`.

### Start the game

The game shows a notice when it loads SDK plugins. Accept it to continue.

### Open Sightline

When you are in the game, press :kbd[Ctrl + Shift + M].

### Turn on multi-monitor mode

Sightline edits the game's **custom multi-monitor mode**. If it is off, the window is dimmed and shows a single button: **Turn on multimon mode (restarts the game)**.

Click it. The game saves your progress, closes, and Steam starts it again a moment later, already in the right mode. Open Sightline again and start editing.

To go back to a single screen later, use **Turn off** on the **Settings** page (see [Hotkey and settings](../02-guides/07-hotkey-and-settings.mdx#back-to-one-screen)).

::::

> [!TIP] Already using multi-monitor mode?
> If your game is already in custom multi-monitor mode, there is no button: Sightline picks up your current layout the first time you open it. Nothing changes until you press **Save**.

> [!NOTE] Not using Steam?
> Sightline asks Steam to start the game again. If your copy of the game is not on Steam, it still turns the mode on and closes the game; just start it again yourself.

## Updating

Close the game and replace `sightline.dll` with the new version. Your profiles, backups and settings are kept.

## Uninstalling

Delete `sightline.dll` and `sightline.ini` from the `plugins` folder. Your `multimon_config.sii` stays as you last saved it. To remove Sightline's files too, delete the `.sightline` folder in the game's documents folder.
