## Open and close the window

Press :kbd[Ctrl + Shift + M] to open the **Sightline** window, and again to close it. You can also close it with the **×** in its title bar. To use another shortcut, see [Hotkey and settings](../02-guides/07-hotkey-and-settings.mdx).

While the window is open:

- **Your mouse and keyboard go to Sightline.** The camera does not turn and the truck does not react to keys.
- **Your wheel, pedals and controllers stay with the game.** Sightline never touches them.
- The game keeps running, so you see every change as you make it.

The window remembers where you left it, its size and the page you were on.

## The pages

The menu on the left opens one page at a time:

| Page | What it is for |
| :--- | :--- |
| **Layout** | One tab per view, with all its settings. **+** adds a view. |
| **Start from...** | The game's templates and the panorama builder |
| **HUD** | Where the HUD and menus are drawn |
| **Profiles** | Save and load named layouts |
| **Backups** | Copies of your file from before each Save |
| **Settings** | The hotkey, the outlines on the screen, Eyefinity and Surround, and turning multi-monitor mode off |

Hover over the **name** of any setting to read what it does. The small diamond at the end of the name means there is help to read.

## Working with values

- **Drag** a field left or right. While you drag, the mouse pointer is hidden and stays put, so you can keep going past the edge of the screen. It comes back where it was when you let go.
- **Double-click** a field, or :kbd[Ctrl] + click it, to type an exact value. Press :kbd[Enter] to apply.
- A **reset button** (a circular arrow) appears at the end of a field you have changed. Click it to put that one value back, either as it is saved in your file or to its default. Hover over it to see which value it goes back to.
- When Sightline asks before doing something, a click outside the question or :kbd[Esc] is the same as **Cancel**: nothing changes.

## Changes are live, saving is not

Every change is applied to the game **immediately**, but your `multimon_config.sii` file is **not** changed. While something differs from the file, the bottom of the window shows **● Unsaved** and the **Save** button turns cyan.

The buttons at the top of every page:

| Button | What it does |
| :--- | :--- |
| **Undo**, **Redo** | Step back and forward through your changes. Also :kbd[Ctrl + Z], and :kbd[Ctrl + Y] or :kbd[Ctrl + Shift + Z]. |
| **...** | **Revert to the saved file** throws away your live changes. **Read again from the game** picks up changes you made in the game's console. |
| **Save** | Writes the current layout to `multimon_config.sii`. A copy of the old file is kept first. |

> [!TIP]
> Experiment freely. **Undo** steps back one change at a time, and **Revert to the saved file** brings back your saved layout at once. Changes you do not save are also gone when you restart the game.

> [!NOTE]
> Undo, Redo and Revert reload the whole layout, so the game may stutter once.

## Where Sightline keeps its files

Everything Sightline writes lives in one folder inside the game's documents folder:

```folder
Documents/
  American Truck Simulator/
    multimon_config.sii
    .sightline/
      profiles/
      backups/
      settings.ini
      sightline.log
```

Only the window's position is kept elsewhere, in `sightline.ini` next to the plugin. There is nothing to edit in it.

The only file outside these that Sightline changes is `multimon_config.sii`, and only when you press **Save** or restore a backup. Turning multi-monitor mode on or off also changes one of the game's own settings (`r_multimon_mode`), which the game keeps in its `config.cfg`.
