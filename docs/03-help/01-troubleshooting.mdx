### Nothing happens when I press Ctrl + Shift + M

- Check that `sightline.dll` is in `<game folder>\bin\win_x64\plugins\`.
- Check that the game uses the **DirectX 11** renderer. Sightline does not work with DirectX 12 or OpenGL.
- Make sure the game window is in front: the hotkey only works while the game has focus.
- If you changed the hotkey, the current one is shown at the bottom of the window and in `settings.ini`.
- Open the game console: Sightline prints a line starting with `[sightline]` when it loads, with the hotkey it is using.

### The window says "Custom multimon mode is off"

The game is not in custom multi-monitor mode. Close the game, set `uset r_multimon_mode "4"` in `config.cfg`, and start it again. The mode cannot be changed while the game is running. See [Installation](../01-getting-started/02-installation.mdx).

### The window says the game console could not be found

Sightline could not connect to the game's command system, usually after a game update it does not know yet. Editing is disabled to keep the game safe. Look for an update of Sightline and include `sightline.log` if you report it.

### The game froze for a moment when I changed a size

That is the game rebuilding the view's image. It happens once per size change. Sightline applies sizes only when you release the slider or the edge to keep it to one stutter.

### The game crashed when I turned off render_exterior

That is a known game crash with `render_exterior` turned off on a regular view. Avoid it, or only use it on a view that shows nothing but the dashboard.

### My layout is gone after restarting the game

Live changes are kept only until the game closes. Press **Save** to write them to `multimon_config.sii`. If you saved by mistake, use **Restore backup**.

### The outlines do not match my screens with Eyefinity or Surround

Set **Physical screens side by side** to the number of screens in your group. See [Eyefinity and Surround](../02-guides/06-eyefinity-and-surround.mdx).

### A key in my hotkey also does something in the game

That should not happen while the hotkey's modifier keys are held. If it does, change the hotkey to another combination and report it, with `sightline.log`.

## The log file

Sightline writes what it does to `sightline.log`, next to the plugin:

```
<game folder>\bin\win_x64\plugins\sightline.log
```

The previous session's log is kept as `sightline.prev.log`. Attach both when you report a problem.
