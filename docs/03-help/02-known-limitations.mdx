## Game behaviour

- **Turning off `render_exterior` on a regular view crashes the game.** Sightline asks for confirmation first.
- **Changing a view's size makes the game stutter briefly.** Sizes are applied when you release the slider or edge.
- **`r_multimon_mode` cannot change while the game runs.** Set it in `config.cfg` with the game closed.
- **Straight lines bend where two views meet.** Each view is a flat camera; this is normal in panoramas and multi-screen setups.

## Sightline

- Works only with the **DirectX 11** renderer.
- **Tested** on American Truck Simulator 1.62.1.1, with one monitor and with two monitors in AMD Eyefinity. Euro Truck Simulator 2 and three-screen setups are supported but **not tested yet**.
- With Eyefinity or Surround, screens must have the same resolution for **Physical screens side by side** to line up, and bezel compensation should be off.
- A game update may change things Sightline relies on. If editing is disabled after an update, look for a new version.
