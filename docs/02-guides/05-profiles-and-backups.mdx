## Profiles

A profile is a saved layout with a name, such as *Triple screens* or *Street view*. Open the **Profiles** page: each profile is a row with a small drawing of its views, its name and a summary such as *3 views · HUD centre third*.

| Action | How |
| :--- | :--- |
| Save the current layout | Click **+ Save current layout**, type a name and press **Enter** (or click **Save**). **Esc** cancels. |
| Load a profile | Click **Load** on its row, or double-click the row. It is applied immediately. |
| Update a profile with the current layout | **...** on its row, then **Update with current layout**. Sightline asks in the row before replacing it. |
| Rename a profile | **...** on its row, then **Rename**. Type the new name and press **Enter**; **Esc** keeps the old one. |
| Delete a profile | **...** on its row, then **Delete**. Sightline asks in the row first; the file goes to the Recycle Bin. |
| Find a profile's file | **...** on its row, then **Show in folder**. **Open folder** at the bottom opens the whole folder. |

Names can use letters, digits, spaces, `-` and `_`, up to 40 characters, and two profiles cannot share a name.

### Which profile is running

The profile the game is running has a cyan bar on the left and the label **ACTIVE**. Sightline finds it by comparing layouts, so it is marked even after you restart the game. When you change something after loading a profile, the label turns to **ACTIVE · CHANGED**: **Reload** brings the profile back, and **Update with current layout** keeps your changes in it.

> [!NOTE] Loading is not saving
> **Load** shows the profile in the game, but your `multimon_config.sii` is not changed until you press **Save**. That way you can try a profile and go back with **Undo**.

### Share a profile

Every profile is a normal `multimon_config.sii` file in:

```
Documents\<game>\.sightline\profiles\<name>.sii
```

Send that file to a friend. They copy it into the same folder on their computer, and it appears in the list within a few seconds.

## Backups

Sightline keeps copies of your file automatically:

- **Original**: the first time you open Sightline, it keeps a copy of your `multimon_config.sii` from before you used it. This one is never deleted.
- **Before every Save**: the file as it was before you saved. The 7 newest are kept; change that with **Copies to keep**.
- **Before every restore**: the current file, so a restore can be undone too.

To go back to one of them, open the **Backups** page, click a copy in the list and click **Restore selected**. That one **does** replace your `multimon_config.sii`, and it is applied to the game immediately.

**Delete** sends the selected copy to the Recycle Bin. The original cannot be deleted from Sightline.

Backups are in `Documents\<game>\.sightline\backups\`. **Open folder** takes you there.
