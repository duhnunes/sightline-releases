## Profiles

A profile is a saved layout with a name, such as *Triple screens* or *Street view*. Use the **Profiles** section:

| Action | How |
| :--- | :--- |
| Save the current layout | Type a name and click **Save as profile**. If the name exists, Sightline asks before replacing it. |
| Load a profile | Select it and click **Load**. It is applied immediately. |
| Replace a profile with the current layout | Select it and click **Update**. |
| Delete a profile | Select it and click **Delete**. It goes to the Recycle Bin. |
| See profiles copied in by hand | Click **Rescan**. |

Names can use letters, digits, spaces, `-` and `_`, up to 40 characters.

> [!NOTE] Loading is not saving
> **Load** shows the profile in the game, but your `multimon_config.sii` is not changed until you press **Save**. That way you can try a profile and go back with **Revert to file**.

### Share a profile

Every profile is a normal `multimon_config.sii` file in:

```
Documents\<game>\.sightline\profiles\<name>.sii
```

Send that file to a friend. They copy it into the same folder on their computer and click **Rescan**.

## Backups

Sightline makes backups automatically:

- **Original**: the first time you open Sightline, it keeps a copy of your `multimon_config.sii` from before you used it.
- **Before every Save**: the file as it was before you saved. The 10 newest are kept.
- **Before every restore**: the current file, so a restore can be undone too.

To go back to one of them, click **Restore backup**, pick it from the list and click **Restore**. That one **does** replace your `multimon_config.sii`, and it is applied to the game immediately.

Backups are in `Documents\<game>\.sightline\backups\`.
