title: View settings

In multi-monitor mode, each **view** (called a *monitor* in the game's file) is a separate camera drawn in its own rectangle of the game window. Each one has a tab on the **Layout** page.

The settings use plain names. The name the game's file uses is shown in each setting's help, so you can match them with `multimon_config.sii`.

## Position on screen

| Setting | Unit | Meaning |
| :--- | :--- | :--- |
| **Left** | % | Left edge of the view, from the left of the game window |
| **Top** | % | Top edge of the view, from the top of the window (larger values move it down) |
| **Width** | % | Width of the view, as a part of the window's width |
| **Height** | % | Height of the view, as a part of the window's height |

These four apply when you **release** the field: changing them on every mouse movement makes the game stutter. The outline on the screen follows while you drag. The [on-screen editor](./01-on-screen-editor.mdx) is usually the easiest way to set them.

## Direction

| Setting | Unit | Meaning |
| :--- | :--- | :--- |
| **Turn** | degrees | Turns the view. **Positive turns left**, negative turns right. |
| **Tilt** | degrees | Tilts the view up or down. |
| **Roll** | degrees | Rotates the view around its centre. |

## Field of view

| Setting | Unit | Meaning |
| :--- | :--- | :--- |
| **Horizontal** | degrees | **Auto** (`0`) uses the game's field of view. Any other value is used directly, and the vertical one follows the view's shape. |
| **Vertical** | degrees | The same, starting from the vertical field of view. |

## Camera position

Moves this view's camera away from the normal position, in metres:

| Setting | Negative | Positive |
| :--- | :--- | :--- |
| **Sideways** | left | right |
| **Up / down** | down | up |
| **Forward / back** | forward | back |

For example, **Up / down** at `3 m` raises the camera roughly the height of a truck.

## What is drawn

| Setting | Meaning |
| :--- | :--- |
| **Cabin interior** | Draws the cab interior. Turn it off for a camera outside the truck. |
| **World outside** | Draws the world outside the cab. Meant for a view that only shows the dashboard. |

> [!DANGER] Turning off World outside
> Turning **World outside** off on a regular view **crashed the game** in testing. Sightline asks for confirmation first. Save your work before trying it.

## Advanced

Closed by default, for settings most layouts never need:

| Setting | Meaning |
| :--- | :--- |
| **Turn, in views** | Turns the view by whole views: `1` = one view to the side, measured with the primary view's field of view. Added to **Turn**. |
| **Tilt, in views** | The same, vertically. Added to **Tilt**. |
| **Crop left**, **Crop top**, **Crop width**, **Crop height** | Which part of the camera's image is drawn in the view. Changing them changes the image's proportions; correct that with the field of view. |

## Primary view, removing views

- The **primary view** is the base for the "in views" settings of the others, usually the view in front of you. Its tab has a cyan dot. On another view, **Make primary** makes that one the primary view.
- **Remove view** deletes the view after a confirmation. **Undo** brings it back, and like everything else it is only written to the file when you press **Save**.

## Add a view

Click **+** after the last tab. Sightline suggests a name and a place to the right of the last view; change them if you like and click **Add view**. Names can use letters, digits and `_`; `ui` is reserved by the game.
